Tools

A collection of useful and less useful tools for our LBG.

Overview

All tools listed below run entirely on your browser, so no data is collected and you can safely use these tools on any confidential confidential data. This also means that if you refresh the page, your progress will be gone.

  • QR Code generator: generate a custom QR code with LBG/Karel logo that lasts forever.
  • Img processor: remove backgrounds from images & more.
  • pdf tools: Convert images to PDF and merge PDF's together.
